# Project documentation

This folder contains the documentation produced for the modelling work. The files at the
repository root (`CHALLENGE.md`, `DATA.md`, `EVALUATION.md`, `SUBMISSION.md` and `RULES.md`) remain
the official challenge documentation. The files below explain our implementation and research
decisions.

## Start here

1. [ARCHITECTURE.md](ARCHITECTURE.md) — how data, features, models and reports flow through the
   repository.
2. [ROADMAP.md](ROADMAP.md) — what is complete, what is still experimental and what should be
   done next.
3. [experiments/benchmark.md](experiments/benchmark.md) — consolidated benchmark and conclusions.
